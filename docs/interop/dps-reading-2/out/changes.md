# Changes after the first run

The first run of every suite is kept as it ran in `first-run/` (suites at 12:27:12Z; replay, see C06 and C07). Intermediate runs are in `runs/run2` to `runs/run5`; the results the README reports are in `final/`. Each change below says what changed, on which sentence of the text it rests, and whether the fault was in the check (the code that implements the text) or in the harness (the code that runs the cases and compares).
